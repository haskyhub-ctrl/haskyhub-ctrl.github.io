💾 Quản lý Sao lưu & Phục hồi CSDL

Tự động sao lưu định kỳ, xuất file snapshot SQL và phục hồi dữ liệu hệ thống bất kỳ lúc nào

ℹ️ Thông tin về File Sao lưu Dữ liệu (.sql / .db)

📦 Dữ liệu bên trong file:
  • Toàn bộ tài khoản, mật khẩu phân quyền (Admin, Cán bộ, Cơ sở)
  • Tất cả phiếu khảo sát PCCC, điểm số, mức độ nguy cơ
  • Toàn bộ nhận định chuyên sâu của AI & lộ trình khắc phục
  • Kho 131 câu hỏi, danh mục và các phương án trả lời
🔍 Cách xem nội dung file .sql:
  • File .sql là văn bản thuần (plain text UTF-8).
  • Mở trực tiếp bằng Notepad, Notepad++, VS Code để xem các lệnh INSERT dữ liệu.
  • Mở trực quan bằng các phần mềm quản trị CSDL như DBeaver, pgAdmin 4, Navicat.
⚡ Tính năng Phục hồi (Restore):
  • Cho phép quay ngược trạng thái hệ thống về bất kỳ thời điểm nào bằng nút "🔄 Phục hồi".
  • Hỗ trợ tải file .sql từ máy tính lên để nạp lại dữ liệu sau khi cài lại máy chủ.
